🏥 Projeto Sentinela

O Projeto Sentinela é uma aplicação desenvolvida para auxiliar na organização e gerenciamento de informações hospitalares.

🚀 Objetivo

O projeto foi criado com o objetivo de aplicar conhecimentos de desenvolvimento de software e criar uma solução prática para o ambiente hospitalar.

🛠️ Tecnologias
JavaScript
Node.js
Outras tecnologias utilizadas no projeto
⚙️ Como executar
git clone https://github.com/s4muellucas/projeto-sentinela.git
cd projeto-sentinela
npm install
