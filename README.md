🏥 Projeto Sentinela

Sistema web desenvolvido para simular o gerenciamento de atendimentos hospitalares, organizando etapas como cadastro de pacientes, triagem, consultas, medicações, internações e chamadas em TV.

🚀 Funcionalidades
🔐 Sistema de login
👤 Cadastro de pacientes
🩺 Triagem de pacientes
🚦 Classificação de risco
👨‍⚕️ Painel médico
💊 Registro e consulta de medicações
🏥 Registro de internações
📺 Sistema de chamada de pacientes na TV
💾 Armazenamento dos dados em JSON
🌐 API utilizando Node.js e Express
🛠️ Tecnologias utilizadas

▶️ Como executar
1. Clone o repositório
git clone https://github.com/s4muellucas/projeto-sentinela.git
2. Entre na pasta
cd projeto-sentinela
3. Instale as dependências
npm install
4. Inicie o servidor
npm start

O sistema ficará disponível em:

http://localhost:10000
🎯 Objetivo

O Projeto Sentinela foi desenvolvido como projeto prático para aplicar conhecimentos de desenvolvimento web, criação de APIs, manipulação de dados e integração entre frontend e backend.
